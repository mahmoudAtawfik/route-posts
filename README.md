# Route Posts – Social Media Application

A modern and responsive social media web application built with **Angular 21** and **TypeScript**. Route Posts allows users to connect, share posts, interact with others, manage their profiles, and stay updated through notifications.

## 🚀 Features

- **Authentication:** User registration and login.
- **Posts Feed:** Browse and explore posts.
- **Post Management:** Create, view, and manage posts.
- **User Profiles:** View and manage personal and public profiles.
- **Follow System:** Follow and unfollow users.
- **Likes & Comments:** Like posts, add comments, and reply to comments.
- **Bookmarks:** Save posts and access them later.
- **Notifications:** View and manage user notifications.
- **Privacy Controls:** Control post visibility and privacy settings.
- **Responsive Design:** User-friendly interface across different screen sizes.

## 🛠️ Technologies Used

- Angular 21.2.23
- TypeScript
- Tailwind CSS
- Flowbite
- RxJS
- Angular Signals
- Angular Router
- Angular HttpClient
- REST API Integration

## Development Setup

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 21.2.23.

### Prerequisites

- Node.js 24.19.0
- npm 11.17.0

### Installation

Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

Navigate to the project directory:

```bash
cd route-posts
```

Install dependencies:

```bash
npm install
```

## Development Server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to [http://localhost:4200/](http://localhost:4200/).

The application will automatically reload whenever you modify any of the source files.

## Code Scaffolding

Angular CLI includes powerful code scaffolding tools. To generate a new component, run:

```bash
ng generate component component-name
```

For a complete list of available schematics, run:

```bash
ng generate --help
```

## Building

To build the project, run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory.

## Running Unit Tests

To execute unit tests with the configured test runner, run:

```bash
ng test
```

## Running End-to-End Tests

For end-to-end testing, run:

```bash
ng e2e
```

Angular CLI does not include an end-to-end testing framework by default. You can choose one that suits your needs.

## API Integration

The application integrates with a REST API to manage authentication, users, posts, comments, bookmarks, and notifications.

Make sure the API configuration is properly set up before running the application.
